# Routine: feature build

1. Board card → doing.
2. gather-context skill.
3. `rag_search` `RAG/recipes/` + prevent checklist (`full-stack-hunt-prevent`): read `data/bug-memory/anti-patterns.md` before the first write.
4. Implement with surgical-edit using the recipe’s **Shape** (ports if the target stack differs).
5. Hunt the diff. Gate 0; close findings with a prevention artifact.
6. Verify.
7. Refine the recipe (`recipe-refine` log line). Upgrade `RAG/library/` (`repo-library`). Move card → review, write discovery.
