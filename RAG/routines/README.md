# Routines

Repeatable checklists the agent can follow.

- `feature-build.md` — gather → recipes + prevent → edit → hunt the diff → verify → refine recipe → upgrade library
- `hunt-prevent.md` — audit or build hunt+prevent loop
- `refine-recipes.md` — curious study → recipe card → hunt holes → refine after ship
- `repo-library.md` — analyze/scaffold → load → ship → upgrade roadmap/tests/edges
