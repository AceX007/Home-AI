# Library schema

Tree under `RAG/library/`. STATUS is the only file the workbench meters parse.

| File | Role |
|------|------|
| STATUS.md | counts + phase |
| ROADMAP.md | phases, `- [ ]` / `- [x]`, last analyzed |
| FEATURES.md | table of slugs |
| features/<slug>.md | works / made / recipe / tests / edges |
| TESTS.md | table: id, proves, feature, status, path |
| EDGES.md | table: id, case, feature, status |

Test status: `required` | `done` | `missing`. Edge status: `tracked` | `tested` | `wont`.
