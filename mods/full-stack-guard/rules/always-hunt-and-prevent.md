alwaysApply: true
---
Hunt and prevent are one loop. Never hunt without a prevention artifact. Never ship an edit without the anti-pattern checklist, then hunt the diff. Read `data/bug-memory/anti-patterns.md` and `rag_search` `RAG/recipes/` before the first write. If `RAG/library/ROADMAP.md` is missing, run skill `repo-library` first. Follow `full-stack-hunt-prevent`, `recipe-refine`, and `repo-library`. Be curious: how this ports, where it is weak, what hole it has. After ship, refine the recipe and upgrade the library. Cap class `hunt-*` at 3–5. Repro is a test or exact code path, not an exploit write-up.
