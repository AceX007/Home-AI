# Gather context

Do not open the whole repo in your head.

1. `rag_search` the task (skills, discoveries, working code).
2. `glob` only if you do not know the path.
3. `grep` for the symbol or error.
4. `fs_read` the smallest file or `code_outline` first.
5. Independent tools in parallel.

Stop gathering when you can name the files you will change.
