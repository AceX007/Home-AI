# Verify and remember

VERIFY
- Read back what you wrote.
- Run the relevant test or command.
- If UI changed, say what you could not click yourself.

REMEMBER
- `rag_write` folder `discoveries` with: task, files, commands, what actually worked.
- Refine the matching `RAG/recipes/` card (skill `recipe-refine`): what worked, what failed, what to try next.
- Keep it under ~40 lines. Future-you is a 2B with FTS, not a 400k context model.
